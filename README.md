# 수학천재 (MathGenius)

초등학교 1~6학년 수학을 **눈으로 이해하고 직접 조작하는** 인터랙티브 학습 웹앱입니다.

> **개발 초기 버전** — 개념 설명 → 체험 → 문제 → 단계별 해설을 구현합니다. 콘텐츠는 계속 추가합니다.

## 제품 방향

- 학년별 학습 탐색과 취약 개념 중심의 학습
- 수학적으로 정확한 시각화: SVG + CSS + 계산 엔진
- 학생이 손으로 조작할 수 있는 수학 교구
- 오답 시 단계별 원리 설명
- 반응형 웹 우선, 이후 Android (Capacitor) 확장

## 설치와 실행

```bash
npm install
npm run dev
```

Node.js 20.19+ 또는 22.12+ 환경을 권장합니다. 개발 서버에 표시되는 로컬 주소로 접속합니다.

```bash
npm run build
npm run preview
```

## MVP 구현 범위

- **2학년:** 받아올림 — 10개 묶음 시각화
- **5학년:** 분모가 다른 분수의 덧셈 — 통분과 분수 막대
- **6학년:** 비와 비율 — 구슬 조작과 백분율
- 개념별 3단계 가이드, 자동 문제 출제, 정답 판정, 풀이
- 웹 브라우저의 localStorage에 익명 학습 진도 저장
- 1~6학년 학습 목차 (미개발 단원은 준비 중으로 표시)

## 구조

```text
src/
  App.tsx              화면과 학습 진행 상태
  components/
    Visuals.tsx        수학 시각화 컴포넌트
  curriculum.ts        학년/레슨 메타데이터
  math.ts              정답 검증·문제 생성·풀이 엔진
  styles.css           화면·애니메이션·반응형 스타일
```

## 교육·안전 원칙

- 모든 문제 정답은 수학 함수로 계산하여 AI의 부정확한 계산에 의존하지 않습니다.
- 교육과정·문항·설명 검수 및 학년별 콘텐츠 확장은 출시 전에 진행합니다.
- 초기 MVP는 계정을 수집하지 않으며, 학습 기록은 사용자 기기에만 저장됩니다.
- 추후 아동 개인정보 처리 시 관련 법령 및 보호자 동의 설계를 선행합니다.

4. 학습 계정 및 보호자 대시보드
