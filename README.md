# 수학천재 · MathGenius

> 초등학교 1~6학년 수학의 개념을 그림으로 배우고, 문제를 풀고, 단계별로 해설을 보는 반응형 학습 웹앱

## 만 14세 미만 가입 — 학부모 사전승인

- **학부모 먼저 가입 → 법정대리인 동의 이메일 발송 → 학부모 명시적 이메일 회신 → 운영자 회신 확인 → 승인 코드 발급 → 학생 소셜 로그인** 순서로 구현했습니다.
- 신규 만 14세 미만 학생의 직접 프로필 생성은 DB 정책에서 차단하며, 확인된 승인 코드에 대해 서버 RPC가 학생 계정과 학부모 연결을 원자적으로 등록합니다.
- 동의 요청·발송·검증·철회 상태 기록과 학생 기록 접근 차단 정책을 분리합니다.
- 실제 이메일 발송에는 Supabase Edge Function과 이메일 공급자 설정이, 승인에는 실제 운영자의 동의 회신 검토가 필요합니다. 법무 검수 전 공개 운영하지 마세요.

관련 문서: **[법정대리인 동의 운영·배포 안내](docs/GUARDIAN_CONSENT.md)**.

## Google·네이버 검색 최적화 준비

- 홈페이지에 학부모·초등 교사·교육 관계자별 안내 콘텐츠와 **검색로봇이 자바스크립트 없이 읽을 수 있는 HTML 본문**을 추가했습니다.
- `/for-parents/`, `/for-teachers/`, `/for-education/`, `/curriculum/`, `/curriculum/grade-1/`부터 `grade-6/`까지 10개 정적 안내 페이지를 빌드 중 생성합니다.
- 실제 도메인을 `SITE_URL`로 전달하면 canonical URL, 웹앱/조직/웹페이지 구조화 데이터, Google·네이버 인증 메타정보 및 11개 URL 사이트맵을 생성합니다.
- 배포 도메인이 정해지지 않은 상태에서는 잘못된 canonical·sitemap을 작성하지 않습니다.
- 검색 노출은 보장되지 않습니다. 교과·교육기관의 공식 인증을 주장하지 않으며 학생/학부모 개인 데이터는 검색 대상 페이지에 포함되지 않습니다.

배포 및 검증: **[Google·네이버 SEO 설정 문서](docs/SEO_DEPLOYMENT.md)**.

## 회원제 학습관리 확장 브랜치 · 2026-11-23

- 신규 방문자는 **랜딩페이지**에서 Google/Kakao 로그인 또는 **GUEST 체험**을 선택합니다.
- 로그인 시 역할(학생/학부모), 학생 학년, 필수/선택 동의 절차를 제공합니다.
- 학생은 맞춤 학습/복습과 숙제를, 부모는 동의·권한 확인된 학생의 학습 기록·숙제 관리를 이용합니다.
- 단원별 정오답/성취기준 진도, 활동 시간, 반복 방문 이력을 분리 저장합니다. 기존 GUEST 로컬 기록은 계속 유지됩니다.
- **필수:** 실제 Google/Kakao 로그인은 Supabase 프로젝트·OAuth 자격증명·SQL 마이그레이션 설정 후 가능합니다.
- **아동 보호:** 만 14세 미만 학습 기록 기능은 외부 법정대리인 동의 검증 연동 전까지 잠깁니다. 개발용 약관은 법적 검토 미완료입니다.

설정·보안·출시 체크리스트는 **[회원/데이터 설정 문서](docs/MEMBERSHIP_SETUP.md)** 를 참조하세요.
레거시 학습 화면 단독 QA 진입 주소는 `/?guest=1`입니다.

## 구현 현황 · 2026-11-22

- **1~6학년, 1·2학기 전체 71개 교재형 단원** 등록·탐색·학습 가능
- **83개 문제 유형 엔진**: 계산·수의 구조·분수·측정·기하·통계·그래프·비율 등
- 모든 단원은 개념 설명, SVG/CSS 시각화, 4지선다 자동 출제, 정답 판정, 3단계 풀이를 연결
- 복합 단원(평균과 가능성, 약수와 배수, 부피와 겉넓이 등)은 **여러 유형이 순차 교체**
- 국가 교육과정의 **121개 성취기준 코드(1~2학년군 29개, 3~4학년군 47개, 5~6학년군 45개)**를 카탈로그에 수록하고 관련 단원에 연결
- **성취기준 121개 독립 수업** + **88개 세부 개념 평가** + **기준마다 자동 적용 문제**
- **기준별 검색/학년군 필터/학습 진도** 및 기준별 평가 진행에 따라 전환되는 학습 단계
- **전용 조작 교구:** 평면도형 넓이 4종, 위·앞·옆에서 본 쌓기나무, 각기둥/원기둥 전개도 접기
- **소수 곱셈을 100칸 격자로 표현:** 0.9 × 0.6 = 0.54를 겹친 54칸으로 시각화하고, 반복 덧셈은 반드시 10으로 나눠 소수의 의미를 유지
- **합동·대칭 도형 직접 조작:** 나비의 선대칭·평행사변형의 점대칭·집 모양의 합동을 드래그/회전 손잡이/키보드로 체험

- **각기둥·각뿔:** 3~8각형 밑면의 실제 3D 모형을 직접 회전, 면/모서리/꼭짓점 직접 선택, 정확한 전개도 면 대응
- **원기둥·원뿔·구:** 회전 가능한 입체 곡면, 평평한 밑면 클릭, 곡면의 펼침과 구의 전개도 한계
- **부피·쌓기나무·방향별 보기:** 1cm³ 정육면체를 문제에 나온 개수만큼 실제로 쌓고 층별로 계산, 문제 크기대로 투영
- **원그래프·띠그래프·수의 규칙·단위 환산:** 그래프 경계/수 카드/단위 조각 자체를 터치·드래그
- **선제적 교구 품질 검증:** [83개 학습 유형과 121개 성취기준 매핑·교구별 QA 현황](docs/INTERACTIVITY_AUDIT.md)
- **83개 전 주제에 16종 직접 조작 교구 연결**: 클릭·터치·호버·드래그·슬라이더·색칠·회전·쌓기 및 즉시 값 변화
- **주제별 탐구 지시문**: '블록을 눌러 세어 보세요'처럼 지금 할 동작을 구체적으로 안내
- 기존 분수 막대의 **동일 길이·등분 점선**을 직접 색칠하고, 등분 수를 바꿔 분수의 크기를 체험
- 모바일/태블릿에서 학년·학기·단원 선택 가능; 문제 단계에서는 핵심 시각화와 답안의 화면 공간을 우선 확보
- **단원별 학습 달성:** 개념별 두 문제 연속 정답, 복합 단원은 포함된 모든 개념 달성 시 완료
- **오답 개념별 피드백**과 분수 사칙연산·분수 곱셈의 겹침 영역 시각화
- **실제 Chromium 브라우저 QA**: 휴대폰 세로·가로, 태블릿, 데스크톱 화면과 터치·드래그 확인
- **PWA 오프라인 학습 기반**: 첫 방문 이후 앱 자원을 캐시하여 네트워크가 없어도 학습 기능 사용 가능
- **Android 프로젝트 기반:** Capacitor 설정·SDK 의존성과 생성/동기화 명령 제공(네이티브 프로젝트·APK는 아직 미생성)
- 익명 학습 기록과 개념별 달성 현황을 브라우저 localStorage에 저장

**성취기준 121개 개별 학습실 구현:** 1~2학년군 29개, 3~4학년군 47개, 5~6학년군 45개 모두 각각 독립적으로 선택·조작·학습할 수 있습니다. 개별 목표·원리·탐구 활동·확인 문제·피드백을 새로 작성했고 **복합 기준 세부 문제 88개**를 추가해 총 **209개 수작업 개념 확인 문제**를 갖췄습니다. 각 기준에는 기존 83개 엔진 중 관련된 하나를 이용한 자동 생성 적용 문제도 이어집니다.

**정확한 완성 범위:** 이번 확장은 121개 성취기준별 학습·확인 콘텐츠 **개발 초안**을 제공한다는 뜻입니다. 국가 기준의 모든 지식·기능·과정·태도 요소를 교사 검수로 평가했다는 뜻이 아니며, 독립 문제 생성 엔진이 121개라는 뜻도 아닙니다.

## 실행

Node.js 22 버전 권장.

```bash
git clone https://github.com/tajogood/mathgenius.git
cd mathgenius
npm install --legacy-peer-deps
npm run dev
```

Vite가 표시하는 로컬 주소(기본 `http://localhost:5173`)로 접속합니다.

```bash
npm run build   # TypeScript 검사 + 프로덕션 빌드
npm test        # 정답·보기·성취기준 연결·전체 교구 할당 검증
npm run test:ui # 조작 후 React 화면/숫자 변화 검증
npm run test:viewport # Chromium 실제 화면 폭/높이, 터치 테스트
npm run test:offline # PWA 프로덕션 빌드 후 오프라인 로딩 테스트
npm run preview # 프로덕션 빌드 미리보기
```

GitHub Actions는 main 브랜치의 매 커밋마다 설치·빌드·테스트를 실행합니다.

## 국가 교육과정과 단원의 차이
