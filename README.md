# 수학천재 · MathGenius

> 초등학교 1~6학년 수학의 개념을 그림으로 배우고, 문제를 풀고, 단계별로 해설을 보는 반응형 학습 웹앱

## 구현 현황 · 2026-11-22

- **1~6학년, 1·2학기 전체 71개 교재형 단원** 등록·탐색·학습 가능
- **83개 문제 유형 엔진**: 계산·수의 구조·분수·측정·기하·통계·그래프·비율 등
- 모든 단원은 개념 설명, SVG/CSS 시각화, 4지선다 자동 출제, 정답 판정, 3단계 풀이를 연결
- 복합 단원(평균과 가능성, 약수와 배수, 부피와 겉넓이 등)은 **여러 유형이 순차 교체**
- 국가 교육과정의 **121개 성취기준 코드(1~2학년군 29개, 3~4학년군 47개, 5~6학년군 45개)**를 카탈로그에 수록하고 관련 단원에 연결
- **성취기준 121개 독립 수업** + **88개 세부 개념 평가** + **기준마다 자동 적용 문제**
- **기준별 검색/학년군 필터/학습 진도** 및 기준별 평가 진행에 따라 전환되는 학습 단계
- **전용 조작 교구:** 평면도형 넓이 4종, 위·앞·옆에서 본 쌓기나무, 각기둥/원기둥 전개도 접기
- **83개 전 주제에 16종 직접 조작 교구 연결**: 클릭·터치·호버·드래그·슬라이더·색칠·회전·쌓기 및 즉시 값 변화
- **주제별 탐구 지시문**: '블록을 눌러 세어 보세요'처럼 지금 할 동작을 구체적으로 안내
- 기존 분수 막대의 **동일 길이·등분 점선**을 직접 색칠하고, 등분 수를 바꿔 분수의 크기를 체험
- 모바일/태블릿에서 학년·학기·단원 선택 가능; 문제 단계에서는 핵심 시각화와 답안의 화면 공간을 우선 확보
- **단원별 학습 달성:** 개념별 두 문제 연속 정답, 복합 단원은 포함된 모든 개념 달성 시 완료
- **오답 개념별 피드백**과 분수 사칙연산·분수 곱셈의 겹침 영역 시각화
- **실제 Chromium 브라우저 QA**: 휴대폰 세로·가로, 태블릿, 데스크톱 화면과 터치·드래그 확인
- **PWA 오프라인 학습 기반**: 첫 방문 이후 앱 자원을 캐시하여 네트워크가 없어도 학습 기능 사용 가능
- **Android 프로젝트 기반:** Capacitor 설정·SDK 의존성과 생성/동기화 명령 제공(네이티브 프로젝트·APK는 아직 미생성)
- 익명 학습 기록과 개념별 달성 현황을 브라우저 localStorage에 저장

**성취기준 121개 개별 학습실 구현:** 1~2학년군 29개, 3~4학년군 47개, 5~6학년군 45개 모두 각각 독립적으로 선택·조작·학습할 수 있습니다. 개별 목표·원리·탐구 활동·확인 문제·피드백을 새로 작성했고 **복합 기준 세부 문제 88개**를 추가해 총 **209개 수작업 개념 확인 문제**를 갖췄습니다. 각 기준에는 기존 83개 엔진 중 관련된 하나를 이용한 자동 생성 적용 문제도 이어집니다.

**정확한 완성 범위:** 이번 확장은 121개 성취기준별 학습·확인 콘텐츠 **개발 초안**을 제공한다는 뜻입니다. 국가 기준의 모든 지식·기능·과정·태도 요소를 교사 검수로 평가했다는 뜻이 아니며, 독립 문제 생성 엔진이 121개라는 뜻도 아닙니다.

## 실행

Node.js 22 버전 권장.

```bash
git clone https://github.com/tajogood/mathgenius.git
cd mathgenius
npm install --legacy-peer-deps
npm run dev
```

Vite가 표시하는 로컬 주소(기본 `http://localhost:5173`)로 접속합니다.

```bash
npm run build   # TypeScript 검사 + 프로덕션 빌드
npm test        # 정답·보기·성취기준 연결·전체 교구 할당 검증
npm run test:ui # 조작 후 React 화면/숫자 변화 검증
npm run test:viewport # Chromium 실제 화면 폭/높이, 터치 테스트
npm run test:offline # PWA 프로덕션 빌드 후 오프라인 로딩 테스트
npm run preview # 프로덕션 빌드 미리보기
```

GitHub Actions는 main 브랜치의 매 커밋마다 설치·빌드·테스트를 실행합니다.

## 국가 교육과정과 단원의 차이

- 기준: **교육부 고시 제2022-33호 [별책 8] 수학과 교육과정**.
- 단원 배열: 2022 개정 교재의 학년·학기별 **대표적인 단원 편제**. 교과서 출판사·학교에 따라 배치나 이름이 다를 수 있습니다.
- 성취기준 코드 연결은 **단원 참고 색인**입니다. 개별 학습 내용을 완전하게 성취했다고 판정하는 수단이 아닙니다.
