# 수학천재 (MathGenius)

**그림을 움직이며 원리를 이해하는 초등 수학 웹앱**입니다. React + TypeScript + SVG/CSS로 개발하고, 이후 같은 웹 학습 엔진을 안드로이드 앱에서도 재사용하는 것을 목표로 합니다.

## 현재 구현 (2026년 11월)

현재 화면에 표시되는 **1~6학년의 18개 대표 학습 단원**은 모두 실행할 수 있습니다. 각 단원에 개념 설명, 시각화, 4지선다 문제 자동 생성, 정답 확인, 3단계 풀이가 연결되어 있습니다.

| 학년 | 작동하는 학습 단원 |
| --- | --- |
| 1학년 | 수 가르기와 모으기 · 덧셈과 뺄셈 · 여러 가지 모양 |
| 2학년 | 받아올림 덧셈 · 곱셈구구 · 시각과 시간 |
| 3학년 | 나눗셈의 원리 · 분수의 뜻 · 길이와 시간 |
| 4학년 | 각도와 각도기 · 평면도형의 이동 · 소수의 덧셈 |
| 5학년 | 분수의 덧셈 · 약분과 통분 · 도형의 넓이 |
| 6학년 | 비와 비율 · 비례식 · 입체도형의 부피 |

**범위 관련 주의:** 위 18개는 대표 주제이며 **2022 개정 초등 수학 교육과정의 모든 성취기준과 교과서 단원을 완전히 구현했다는 의미는 아닙니다.** 정확한 성취기준 매핑과 전체 단원 확대는 후속 작업입니다.

### UI/UX

- 분수 막대는 두 그림의 **전체 길이가 동일**하며, 색칠된 영역 위에 **등분 점선**을 그립니다.
- 통분 단계에서 각각의 분모가 같은 수의 칸으로 바뀌는 것을 확인할 수 있습니다.
- 학년 선택 및 개념 학습 화면은 반응형이며, 문제 단계에서는 소개 영역을 숨기고 **문제·답안·시각화**를 우선 표시합니다.
- 아주 작은 가로 화면에서는 문제와 선택지가 먼저 보이도록 시각화 영역을 간소화합니다.
- 모바일 최소 환경에서도 UI가 사용 가능하도록 반응형 규칙이 적용되어 있으나 실제 장치별 시각적 QA는 추가로 진행해야 합니다.

## 설치

Node.js **22.x** 환경을 권장합니다.

```bash
git clone https://github.com/tajogood/mathgenius.git
cd mathgenius
npm install
npm run dev
```

화면에 표시되는 로컬 개발 주소(기본값 `http://localhost:5173`)로 접속합니다.

### 타입 검사·프로덕션 빌드

```bash
npm run build
npm run preview
```

### 수학 엔진 자동 테스트

```bash
npm test
```

18개 주제에서 각각 150개의 문제를 생성해 정답, 보기 중복 여부, 단계별 풀이 데이터의 기본 정합성을 검사합니다. GitHub Actions에서도 빌드와 테스트를 실행합니다.

## 프로젝트 구조

```text
src/
  App.tsx                  학년 선택과 학습 상태, 화면 흐름
  curriculum.ts           18개 주제의 메타데이터와 개념 스크립트
  math.ts                 문제 생성, 정답 계산, 3단계 풀이
  components/
    Visuals.tsx           분수 비교·받아올림·비율 시각화
    MoreVisuals.tsx       15개 대표 주제의 SVG/CSS 시각화
  styles.css              반응형/모바일/문제 화면 스타일
tests/
  math.test.mjs           문제 엔진 자동화 테스트
```

## 원칙 및 다음 개발 과제

- 수학적 정답 검증은 결정론적 함수로 처리합니다. 생성형 AI에 정답 판정을 맡기지 않습니다.
- 현재 계정 및 서버 데이터베이스는 없으며, 익명 진도는 브라우저 localStorage에 저장합니다.
- 초등 전 학년의 **전체** 교육과정 성취기준에 맞춘 레슨 확장·검수
- 장치별 실제 화면 테스트, 접근성 및 조작형 인터랙션 고도화
- 문항 난이도/오답 패턴별 개인화, 보호자 대시보드
- Capacitor 기반 Android 앱 패키징 및 스토어 출시 준비
